# 🎯 KovaaK's Catppuccin Macchiato Theme & Settings

A clean setup inspired by the **Catppuccin Macchiato** palette for KovaaK's UI, HUD, and visuals.

---

## 🚀 Quick Installation

Make sure **KovaaK's is closed** before copying any files.

### 1. 🎨 Theme & HUD Colors (`Palette.ini`)

Determines the color scheme for all menus, UI elements, and HUD icons.

- **Destination:**  
  `%localappdata%\FPSAimTrainer\Saved\Config\WindowsNoEditor`
- **Action:** Replace the existing `Palette.ini` with the provided file.

---

### 2. 🗂️ Assets (Crosshairs, Sounds & Themes)

Default game root directory:  
`C:\Program Files (x86)\Steam\steamapps\common\FPSAimTrainer\FPSAimTrainer`

Drop the respective files into their corresponding folders:

- 🎯 **Crosshairs** ➔ `...\FPSAimTrainer\crosshairs`
- 🔊 **Sounds** ➔ `...\FPSAimTrainer\sounds`
- 🖼️ **Themes** ➔ `...\FPSAimTrainer\Saved\SaveGames\Themes`

---

### 3. ⚙️ Full Configuration (Optional)

If you want to copy my entire settings configuration (sens, binds, UI layout, visuals):

- **Destination:**  
  `C:\Program Files (x86)\Steam\steamapps\common\FPSAimTrainer\FPSAimTrainer\Saved\SaveGames`
- **Action:** Replace your existing `UI.json` and `PrimaryUserSettings.json` files.

> ⚠️ **Note:** Back up your original `.json` and `.ini` files before replacing them!
